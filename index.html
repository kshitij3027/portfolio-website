/ 01 FLAGSHIP python · neo4j · pydantic-ai tested on real attack data

SentinelLite — autonomous SOC

A self-hostable, $0 mini autonomous SOC — and I tested it against real public attack data, not data I made up. It ingests dev-stack telemetry (GitHub, AWS CloudTrail, Okta, Falco) in each vendor's native schema, correlates entities in a Neo4j security graph, runs parallel AI agents on a local Ollama model to triage and investigate, and reconstructs a full MITRE ATT&CK kill chain — all behind a human-approval gate. docker compose up, zero keys.
Caught a supply-chain breach end-to-end in ~2.3 min — 50 alerts in, 42 auto-closed as noise (84%), 8 escalated and correlated into one incident with 5 staged response actions.
Parallel-then-correlate agents — Triage, Identity, Endpoint and SupplyChain agents run under asyncio.gather, each querying the graph for its domain; a Correlator stitches the kill chain with MITRE IDs and graph-path citations.
Real datasets, cited provenance — Splunk Attack Data, the GitHub Advisory DB (CVE-2021-23337, lodash) and invictus-ir CloudTrail. A 780 KB curated subset ships so the demo runs offline right after clone.
Tamper-evident & observable — every decision in a SHA-256 hash-chained audit log, two-tier approval on irreversible actions, plus Prometheus, a 9-panel Grafana board, and SSE-streamed agent traces.

/ 02 FLAGSHIP python · fastapi · postgres rls 18 CRs · 11 SCs · CI ✓

Retell Gateway — enterprise webhook middleware

The hardened boundary between Retell's voice-agent webhooks and Salesforce. Voice events (call_analyzed, call_inbound…) come in signed; REIG verifies them, redacts PII, and upserts to the CRM — built around a CRMAdapter Protocol so a second downstream (ServiceNow) drops in without touching the core.
Trust nothing at ingress — HMAC-SHA256 over body+timestamp with a 5-min skew and constant-time compare; tampered bodies get 401 and an audit row. Idempotency via ON CONFLICT DO NOTHING collapses replay storms to exactly one write.
Isolation in the database, not the app — Postgres row-level security under a non-BYPASSRLS role, default-deny when the tenant is unset, so an app-tier bug can't leak across tenants. Refresh tokens encrypted at rest with pgcrypto.
PII never reaches the CRM — Microsoft Presidio rewrites SSN, email, phone and card spans to <TYPE_REDACTED> before anything persists or hits Salesforce.
Built to be debugged — seven named OpenTelemetry spans stream to Jaeger, tenacity retries upserts (5 attempts, jittered backoff), and inbound caller-hydration answers under a hard 1.8 s budget to keep Retell's 2 s SLA green.

/ 03 FLAGSHIP python · fastapi · redis 130 commits

Inference Gateway — production LLM proxy

This is the thing I'd drop in front of any serious LLM workload. It's a reverse proxy that speaks the OpenAI API on the front and talks to OpenAI, Anthropic, and Ollama on the back — and in between does all the plumbing nobody wants to write twice: semantic caching, rate limiting, priority queuing, circuit breakers, consistent-hash routing, and request journaling.
Two-tier cache — in-process LRU for zero-hop, Redis + sentence-transformers for semantic hits at cosine ≥ 0.95. Cache hit drops latency under 50ms.
Resilience I trust — per-backend circuit breakers with a rolling 60s window, 3-attempt failover, priority queue with backpressure instead of rejections.
Multi-instance from day one — 3 gateway replicas behind Nginx, shared Redis for state, rolling restarts for zero-downtime deploys.
Observability built-in — 14 Prometheus metrics, 4 auto-provisioned Grafana dashboards, TTFT/ITL histograms for streaming.

Agentic RAG — chat + ingestion

A full-stack RAG application with two surfaces: a threaded chat interface with retrieval-augmented responses, and an ingestion pipeline for drag-and-drop document upload with processing tracking. The agent decides what to retrieve, when to hit the web, and when to fall back to text-to-SQL against the user's own data.
Agentic retrieval — the model chooses between vector search, web search, and SQL on the fly. Not just RAG-over-docs; actual tool use.
Supabase as the whole backend — Postgres + pgvector for embeddings, Auth for users, Storage for files, Realtime for ingest progress streaming to the UI.
Typed end-to-end — Pydantic on the FastAPI side, TypeScript + shadcn/ui on the React side. No guessing what's on the wire.
Observable by default — LangSmith traces every agent run so I can debug why it picked the wrong tool at 2am.

/ 05 FLAGSHIP python · pydantic-ai 58 commits

Codagent — terminal coding agent

A terminal-based AI coding agent that translates natural language into shell commands and iterates until the task is done. I wanted something Copilot-shaped that lived in my actual workflow — zsh, not an IDE — with real safety rails, streaming output, and the ability to swap between GPT-5, Claude, and Groq on a single config flag.
ReAct loop, one tool — a single async shell tool with an approval gate. The LLM plans, proposes, and waits for me to say yes.
Two modes — approval (confirm every command) or yolo (auto-run, except dangerous patterns like rm -rf /, git push -f, fork bombs — those always ask).
Multi-provider — OpenAI, Anthropic, OpenRouter. One config flag switches between GPT-5, Claude 4.5 Sonnet, and Grok Code.
Proper terminal UX — Rich for streaming panels, prompt-toolkit for history and completion, two-tier Ctrl-C (cancel the agent first, then exit).
